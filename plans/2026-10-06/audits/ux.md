# Skein UI/UX audit (2026-10-06)

Code: `/mnt/Sabrent/homelab/.alt/merge-perf` (merge/perf). No app file was edited.
Shots: `/mnt/Sabrent/homelab/.alt/ux-audit/shots/` (`<scene>-<1440|1100>-<light|dark>.png`; below `S/` means that folder).
Harness (outside the repo): `/mnt/Sabrent/homelab/.alt/ux-audit/harness/` (`mock.js` fakes the Tauri IPC with 800 repos, `shoot.mjs` drives Helium, `vite.config.mjs` sets `fs.strict=false` because node_modules is a symlink).

Caveats. Linux headless Chromium, not WebView2: scrollbars, native selects, DPI and title-bar behaviour are inferred from code. The mock has no Monaco content, so file compare internals were not judged (out of scope: packet 37/06s). Clicking a branch chip (ref picker) froze the tab with mock refs; I could not screenshot it (item 22 is code-reading only). 1100 px is the app's `minWidth`, and a 1366 or 1920 px laptop at 125-150% DPI lands near it, so 1100 is a main case.

Contrast (`contrast.mjs`, tokens read from the running app): all text pairs pass AA in both themes (dim on panel 5.96 light / 7.32 dark; faint-text on sidebar 4.91 / 7.17; accent button text 5.49 / 9.46; status text on tinted bg 4.8 to 7.5). Non-text: divider `--line` is 1.32:1 light / 1.20:1 dark (decorative, fine); control border `--line-ctl` is 3.35:1 / 3.59:1 (passes 3:1); `--faint` is 3.35 / 3.90 so it must never carry text (no use found). The palette is sound; the problems are layout, state and feel.

Strengths to keep: Formation table and sync rails read well at 1440; skeleton, toast and empty-state components exist; virtual list holds 19 DOM rows and about 60 fps scrolling on 800 repos, and a filter-chip click costs about 32 ms; focus ring is visible; reduced-motion is honoured; History drawer and delete-set confirm are clear.

Overlap legend: **P39** = packet 39 branch cleanup + code search (`ui/39-cleanup-search` touches App.svelte, Tabs, SetView, SetHeader, BulkBar, RowMenu, HistoryDrawer, commands.ts, state.svelte.ts, app.css). **P37** = compare editor replacement (Monaco). **P41** = Settings diagnostics section.
